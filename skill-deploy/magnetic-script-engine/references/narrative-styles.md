# Narrative style library

Each style is a way of carrying the spine (tension → mechanism → action). Pick by what the diagnosis says will break understanding.

| Style | Shape | Fits best when the failure is… | Strong for | Watch out |
|---|---|---|---|---|
| **First-person journey** | A viewer-like character lives the moment; we hear their thoughts; the rule arrives at the moment of decision | Transfer Failure — they know the rule but won't recognize the moment | Patient ed, onboarding, compliance-in-the-moment | Don't let the story bury the locked facts; say them plainly at the decision point |
| **Myth-buster** | State a belief → show why it's wrong → replace with the true model | False Certainty — they think they already get it | Anything with a popular misconception | Don't repeat the myth more than the truth; end on the truth |
| **Explainer / mechanism reveal** | "Here's what's actually happening inside" — one analogy carried through | False Certainty / Fragmentation — rules without a model | Pathophysiology, processes, systems, policies with a logic | Keep to one analogy; don't lecture |
| **Countdown / 3 things** | Numbered items building to the most important | Cognitive Overload — too many rules, no hierarchy | Dense leaflets, checklists, policies | Max 3–5; the last item must be the one job |
| **Before/after scenario** | Same situation twice: without the knowledge, then with it | Transfer Failure | Safety, compliance, customer-facing training | Keep both runs short; the difference must be a visible action |
| **Q&A / "you asked"** | Real-sounding questions answered in sequence | Cognitive Overload — people only need their question answered | FAQs, benefits guides, patient questions | Questions must be sharp and specific, not "What is X?" |
| **Mystery / investigation** | A symptom/problem → clues → the cause | Fragmentation — pieces not connected | Diagnostics, root cause, science/history content | Reveal must be earned; don't drag |
| **Object / system POV** | The heart, the policy, the vaccine "speaks" | Fragmentation / False Certainty — the system is invisible | Science, publishing, kids/teen audiences, High level | Can feel gimmicky at Low; keep it accurate |
| **Stakes story (NGO)** | One person/place → the system behind it → what changes with action | Transfer Failure — cares but doesn't act | Advocacy, fundraising, awareness | Use only real stories supplied by the doc; otherwise use a composite clearly framed as "imagine" |

## Choosing the pair

Two versions should give the prospect a real choice. Good pairings contrast on one of these axes:

| Axis | Pair examples |
|---|---|
| Inside vs outside (story vs model) | First-person journey × Explainer / mechanism reveal |
| Belief vs moment | Myth-buster × First-person journey |
| Hierarchy vs narrative | Countdown × Before/after scenario |
| Answer vs discovery | Q&A × Mystery |

Avoid pairing two styles that share the same axis (e.g. Myth-buster × Explainer both teach a model; they'll read similar).

Default pick when nothing is specified: take the style that best matches the diagnosed failure as Version A, then pick B from the opposite side of the most relevant axis.

## If the user names a style not in this list

Accept it. Map it to the nearest shape above for structure, and keep the spine.
