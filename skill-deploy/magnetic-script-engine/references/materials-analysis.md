# Materials analysis

Build this sheet privately before drafting. Read as the end viewer, not as the client
who wants every section included.

## Select the critical material

- Select the four or five most critical source passages that the viewer must act on.
- Choose one observable job: the behavior the viewer should be able to perform after
  watching.
- Use only urgency, warnings, emphasis or ordering explicitly present in the source to
  rank content. If the source gives no ranking, preserve its priority or order.
- Diagnose an understanding need only when the source or supplied audience brief
  supports it. Otherwise use `Unspecified clarity need`.

Supported internal lenses:

- `False Certainty`: an incorrect rule or assumption is explicitly identified.
- `Cognitive Overload`: the supplied material contains too many competing actions for
  the selected duration.
- `Concept Fragmentation`: source-supplied pieces need clearer organization without a
  new relationship being added.
- `Transfer Failure`: the source or audience brief explicitly identifies difficulty
  applying an instruction in its stated setting.

Never present an internal diagnosis as a fact about the audience.

## Assemble six fields

- `job`: one observable behavior.
- `lockedFacts`: exact locked items with source locations.
- `mechanism`: the exact source passage stating why; leave empty if absent.
- `failureAndHook`: the supported understanding need plus the source-specific decision
  or action the opening will clarify.
- `cutList`: source material intentionally excluded to fit the supplied budget.
- `audienceFit`: only an explicitly supplied profile; otherwise use a neutral voice.

Red-flag rules for the chosen job must survive every duration. Never pad a sparse
source with generic advice.
