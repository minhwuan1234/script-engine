# Countdown / three things

Give the viewer a memorable set of ideas with a sense of progression. You choose
the number, labels and organizing device according to the material; “three things”
is not a compulsory count. Each item should earn its place in the same takeaway.

Try a checklist built as the action unfolds, numbered questions, a visual route or
an accumulating set of source-supported distinctions. Vary how items enter; avoid
repeating an identical introduction for every number. Finish with how the pieces
work together or the source-stated action, rather than rereading the entire list.

An editorial order can improve comprehension without claiming that one item is
more important. Preserve any source-mandated procedural sequence. If counting down,
make clear that the numbers organize the explanation rather than imply an invented
clinical ranking. The items' factual content and conditions must remain sourced.
