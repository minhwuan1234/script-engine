# Script craft — how a magnetic script is built

A document is written to be *complete*. A script is written to be *followed*. Most doc-to-video conversions fail because they keep the doc's logic (complete, sectioned, every caveat equal) and just shorten it. The result is a narrated leaflet. This file is about rebuilding the material around the viewer's attention and the one job they need to do.

## 1. The spine

Every script, in any style, carries this spine:

1. **Tension** — a gap between what the viewer thinks/does and what's actually true or needed. Built from the diagnosis (the likely misunderstanding), never from a generic "health is important".
2. **Mechanism** — why the rule exists, shown simply enough to picture. This is what turns "a rule I was told" into "a thing I understand", and it's what makes the rule survive contact with real life.
3. **Action** — one specific, observable thing to do, with the trigger ("when you see X, do Y").

The narrative style decides *how* the spine is told. The spine doesn't move.

## 2. The hook (0:00–0:15)

The hook is also the free preview in the tool. It has to earn the email on its own.

**It must:**
- Open on something specific to THIS doc in the first sentence — a number, a moment, a wrong belief, an object. A viewer should not be able to guess the hook from the topic name alone.
- Create an open loop: a question the viewer now needs answered, which the script pays off later (say where in your head; make sure it happens).
- Name or imply the viewer's moment ("You're home. The discharge folder is on the counter.").
- Be speakable in ~15s: roughly 30–40 words total. Short lines.

**Hook moves** (pick one; styles and levels bias the choice):
| Move | Shape | Example seed |
|---|---|---|
| The number that doesn't look scary | Reveal a small threshold with big meaning | "Two pounds. That's the number that matters." |
| The wrong belief | State what most people assume, then crack it | "Most people think feeling fine means you're fine." |
| The moment | Drop into a concrete scene | "Tuesday, 7am. The scale says 184." |
| The cost | What happens when this goes wrong, factually | "One in four..." — ONLY if the doc supplies it |
| The contradiction | Two true things that seem to clash | "The pill that makes you pee more is protecting your heart." |
| The dare / challenge (High) | Direct challenge to the viewer | "Bet you can't name the three numbers on your fridge." |

**Hook tests** — fail any, rewrite:
- Swap test: replace the topic noun with another topic. Does the hook still work? If yes, it's generic.
- Stranger test: would someone scrolling with no context understand what's at stake by second 5?
- Promise test: does the rest of the script actually pay off what the hook opened?

## 3. Line-level voiceover rules

- One idea per line. Most lines ≤ 15 words. Vary length — a 3-word line after two long ones is a drumbeat.
- Write for the ear: contractions, second person, present tense. Read it aloud in your head; if you'd stumble, rewrite.
- Concrete nouns over abstractions (OVC): "the scale in your bathroom", not "self-monitoring tools".
- Action verbs over weak verbs: "weigh", "write", "call" — not "ensure", "be mindful of", "it is important to".
- Translate doc jargon on first use, in the same line, without making it a vocabulary lesson: "edema — swelling in your ankles".
- Numbers: say them the way a person would ("two to three pounds overnight"), keep them exactly as the doc states.
- Name structure aloud when listing: "Three numbers. Here's the first." Lists max 3 in one breath; if the doc has 7, group or pick (see §6).
- No throat-clearing: cut "In this video we will", "Let's talk about", "It's important to understand that".

## 4. Structure moves that hold attention

- **Beat length**: a new visual/verbal beat every 5–8s on short-form, 8–15s on long-form. Timestamp rows ≈ beats.
- **Open loops**: plant a question early, pay it off later; one open loop should be alive at any moment until the end.
- **Pattern interrupts**: a change in rhythm, POV, a direct question, a visual reveal — at least one every ~20s on long-form.
- **Show, then name**: demonstrate the mechanism with an image/analogy first, then give the term.
- **Callback**: end by returning to the hook's image/number with new meaning.
- **Analogies**: one strong analogy per script, carried consistently (don't mix sponge + bathtub + traffic jam). The analogy must be accurate at the level it's used.

## 5. The "On screen" column

This column is F's quiet flex — it shows the prospect we think visually for understanding, not decoration.

- Describe what the viewer SEES that explains: a scale readout ticking up, a heart icon as a pump with water backing up, three numbers stacked on a fridge note.
- Where useful, tag the design intent in brackets: `[Reveal mechanism]`, `[Structure info]`, `[Build mental model]`, `[Guide attention]`, `[Contextualize]`. Use tags sparingly — a few per script, where the visual is doing heavy lifting.
- Include on-screen text only when it's the thing to remember (a threshold, a phone-call trigger).
- Don't specify art style or animation technique unless the style demands it (e.g. first-person POV).

## 6. Handling many facts

A 1,800-word doc has 40 facts. A 90-second script holds 5–8. Choose, don't compress.

- Keep: locked facts tied to the one job; the mechanism; the action trigger.
- Group: related rules under one image (e.g. "salt, fluid, weight — they're the same story").
- Push out: secondary rules go to "the rest is in your folder — this video is about the one that catches problems early", or to later episodes if series.
- Never: blur a threshold into vagueness to save words ("gain some weight" instead of "2–3 pounds in a day").
- Long locked lists (e.g. five emergency signs): voice the two most recognisable items, show the full list on screen in the same beat, and note this in Engine notes. Never drop items from both VO and screen.

## 7. Endings

- One action, with trigger, stated plainly — the most quotable line in the script.
- Optional callback to the hook.
- Low level: end with a calm summary line. High level: end with a punch/callback. All levels: no fake urgency.
- Healthcare: the "call your care team when…" instruction appears in the doc's own terms.
- No brand CTA inside the client script unless the user asks (the tool is showing a script for *their* video).

## 8. Anti-patterns — rewrite on sight

- "Did you know…?" as a hook opener
- "In today's video, we'll cover…"
- "X is a serious condition that affects millions" (unless the doc gives the number and it serves the tension)
- "It's important to…", "Make sure to…", "Remember to always…" stacked as a list of rules
- "Let's dive in" / "Stay tuned" / "Smash that like button"
- A rule with no why
- Every line the same length and shape
- Visual column full of "icon of X" with no explanatory job
- Fear without an action ("this could kill you" and then nothing)
- Any line that could be pasted into a script about a different document

## 9. Quality gate

Before output, answer each honestly. Fix failures in the script itself.

| # | Check |
|---|---|
| 1 | Hook passes swap, stranger, and promise tests |
| 2 | The open loop from the hook is paid off, and you can point to the timestamp |
| 3 | Mechanism is shown, not just the rule |
| 4 | The likely misunderstanding from the diagnosis is directly addressed |
| 5 | Every locked fact is present and exactly right; no invented facts/stats/stories |
| 6 | Ends on one observable action with a trigger |
| 7 | Word count within budget; `check_timing.py` shows no dense/thin flags (or they're intentional and noted) |
| 8 | Versions A and B differ in angle/structure, not just wording |
| 9 | No anti-pattern lines from §8 |
| 10 | Reason copy names the understanding problem in plain language and ties it to a script choice |
